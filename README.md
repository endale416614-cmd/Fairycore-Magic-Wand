# Fairycore - Magic Wand

Fairycore - Magic Wand adds five small wands that shape a psycaster's focus into glowing orbs, each of its own element.

A RimWorld mod by Faeris, version 2.02. Workshop page: https://steamcommunity.com/sharedfiles/filedetails/?id=3814383460

## Install

Copy this folder into `RimWorld/Mods`, enable the mod and load it after Harmony.

Skill effects and sounds in this repository are made for this release, so they differ from the Workshop version.
